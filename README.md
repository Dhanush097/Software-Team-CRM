# CRM Mobile

A comprehensive mobile-first CRM solution built for modern business management, team collaboration, and client deliverables.

---

## 📁 Project Structure

```
CRM_Mobile/
├── admin/       # Complete Administrator CRM portal
├── team/        # Team Member CRM portal with OTP authentication
└── customer/    # Client Deliverables & Services Portal
```

### Portals Overview

1. **Admin Portal (`/admin`)**:
   - Complete project oversight, client records, invoicing, and team assignments.
   - Comprehensive metric dashboards and task management.

2. **Team Member Portal (`/team`)**:
   - Secure OTP-based authentication linked with real-time sheet permissions.
   - Daily task trackers, calendar schedules, and contact directory.

3. **Customer Portal (`/customer`)**:
   - Streamlined client dashboard featuring two primary bottom menus:
     - **My Tasks**: Track project deliverables, milestones, and real-time status.
     - **Services**: Explore service packages (Web Development, Marketing, SEO) with direct 1-tap WhatsApp consultation.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS Variables, Alpine.js, Responsive Mobile Layout.
- **Backend / API**: PHP, MySQL / SQLite, Google Apps Script integration.
- **Authentication**: 4-digit OTP with Google Sheets real-time permission validation.
